# YOLOv8_Detection-OperatorRooms

A computer vision system for monitoring an operator room using a custom-trained YOLOv8 model. The model detects people, heads, and phones from video, and the accompanying detection script uses those detections to track occupancy status and flag phone usage while on duty.

## Project Structure

```
YOLOv8_Detection-OperatorRooms/
├── Dataset/               # Training dataset in YOLO format (images, labels, data.yaml)
├── train.py                # Script for training the YOLOv8 model
├── Detect.py                # Script for running inference on video with tracking and status logic
├── Check_labels.py          # Utility script for validating dataset label files
├── README.dataset.txt       # Dataset source information (Roboflow)
├── README.roboflow.txt      # Export metadata generated by Roboflow
├── yolov8n.pt                # YOLOv8 (nano) base model weights
└── yolo26n.pt                 # Additional base model weights
```

## Installation

This project is written in Python and relies on the following core libraries.

```
pip install ultralytics opencv-python numpy
```

If you plan to train or run the model on a GPU, install a version of PyTorch that matches your CUDA setup.

## Dataset

The dataset used for training comes from a Roboflow project named "Loading Room V2" and is organized in standard YOLO format under the `Dataset` folder, with a `data.yaml` file describing the image paths and class names. The classes used by the model include People, Head, and Phone.

`Check_labels.py` is a helper script that can be used to validate the dataset's label files before training, helping catch malformed or mismatched annotations early.

## Training the Model

Training is handled by the `train.py` script, which uses the Ultralytics YOLO library. The workflow is roughly as follows.

1. Load a pretrained base model, `yolov8n.pt`.
2. Call `model.train()` with the desired training parameters, including

   - `data`: path to the dataset's `data.yaml` file
   - `epochs`: number of training epochs
   - `batch`: batch size per iteration
   - `workers`: number of data-loading workers
   - `device`: which device to train on (for example, `0` for the first GPU)
   - `verbose`: whether to print detailed training logs

Example command to start training

```
python train.py
```

Before running, update the model and dataset paths in `train.py` to match their locations on your machine, and adjust `epochs`, `batch`, and `device` to fit your dataset size and available hardware.

Once training finishes, Ultralytics saves the results, including the best-performing weights, under the `runs/detect/` folder, which is created automatically during training.

## Running Inference

`Detect.py` is the main script for applying a trained model to a video source. Its key capabilities include

- detecting and tracking people, heads, and phones frame by frame using ByteTrack
- filtering detections by size and aspect ratio to reduce false positives
- smoothing bounding boxes over time to stabilize the display
- deriving a room status such as "Standby Loading" or "Nobody Here" based on how long people have been absent from the frame
- flagging sustained phone usage by checking whether a detected phone box stays close to a detected head over a number of frames, and displaying how long the phone usage has lasted

Example command

```
python Detect.py
```

Before running, update the model weights path and the video source path inside `Detect.py` to match your setup. Several detection and timing parameters near the top of the script, such as size thresholds, aspect ratio limits, and debounce timers, can also be tuned to fit the camera angle and environment being monitored.
